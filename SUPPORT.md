# Support

## How to get help

Augur uses [GitHub Issues](https://github.com/QuinntyneBrown/Augur/issues) to
track bugs and feature requests. Search the existing issues before opening a new
one to avoid duplicates.

- **Bugs:** open an issue with the Augur version (`augur --version`), your
  operating system, the command you ran and the output you got. Output from
  `--verbosity diagnostic` is helpful; remove API keys and private
  specification text before posting it.
- **Feature requests:** open an issue that describes the problem you want to
  solve.
- **Questions:** open an issue and describe what you are trying to do.
- **Security vulnerabilities:** do not open a public issue. Follow
  [SECURITY.md](SECURITY.md).

Before opening an issue, check the [README](README.md) and the
[specifications](docs/specs).

## Support policy

Augur is maintained on a best-effort basis by its contributors. There is no
guaranteed response time.

Questions about the OpenAI Decisions API, your OpenAI account or billing should
go to [OpenAI support](https://help.openai.com/).
